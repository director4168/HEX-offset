# HEX偏移
作者: director_Carter  
[我的博客](https://director4168.github.io)  


## 关于  
- 仅供娱乐  
通过对文件进行一定量的偏移（偏移量为3），拥有向右偏移（+3）和向左偏移（-3），不建议对大文件进行处理

## 风险：
- 1. 选择文件后将直接进行处理  
- 2. 处理后的文件将直接覆盖掉整个原文件  
- 3. 处理大文件 **可能** 导致数据丢失！
